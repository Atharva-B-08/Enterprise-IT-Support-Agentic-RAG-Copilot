# RB-008: Software Installation and Requests

## Installing approved software

1. Open the **Software Portal** on your laptop.
2. Search for the application.
3. Select **Install**.
4. Wait for the confirmation. Large applications can take up to 20 minutes.

## Application not listed

1. Raise a **Software Request** in the Service Portal.
2. Provide:
   - Name and version
   - Business reason
   - Number of users
   - Whether it handles customer or company data
3. IT and Security review licensing, cost, and risk. This typically takes 5 business days.
4. You are notified of the decision. Approved software is added to the Software Portal.

## Install fails

| Error | Fix |
|---|---|
| "Insufficient disk space" | Free up space (see RB-006) |
| "Installation blocked by policy" | The app is not approved; raise a Software Request |
| Install stuck at 0% | Restart the laptop and retry |
| "Licence unavailable" | Raise a P4 ticket; the licence pool may be exhausted |

## Not permitted

- Cracked or pirated software
- Remote-access tools not approved by IT
- Cryptocurrency miners
- File-sharing tools outside approved options

## Developers

Engineers may install IDEs, language runtimes, and container tools from approved sources. Open-source packages are scanned in CI before release.

## AI tools

Use only approved AI assistants. Do not paste customer data, credentials, or Confidential code into unapproved tools. See the AI Usage Guideline on Confluence.
